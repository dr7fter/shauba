# 05 · 数据库结构与查询纪律

> 新增。凡**查库分析**的任务先读这份。

## ★ 只读快照纪律（违反会读到假数据或破坏线上库）

1. 数据库在 `%APPDATA%\com.shuaba.math\shuaba.db`，**开了 WAL**
2. 分析时必须**同时复制 `.db` + `.db-wal` + `.db-shm`**，否则读不到最新数据
3. 复制目标**不要用 Git Bash 的 `/tmp`**（sqlite3 会报 "unable to open database file"）。
   用项目内路径如 `E:\刷吧\.workbuddy\tmp\`，**分析完立即删除**
4. **只读分析，绝不用 SQL 写原库。** 所有对 DB 的写操作只通过 App 自身命令
5. Python 脚本记得 `con.row_factory = sqlite3.Row`，否则 `r['col']` 报 TypeError
6. ⚠️ **sqlite3 游标复用坑**：在外层 `for x in cur.execute(...)` 循环里再调用
   `cur.execute(...)` 会重置结果集，导致外层只迭代一次就结束。
   **必须用第二个游标**（`cur2 = con.cursor()`）或先 `fetchall()`

标准写法：

```python
import sqlite3, os, shutil
src = os.path.join(os.environ['APPDATA'], 'com.shuaba.math', 'shuaba.db')
tmp = 'E:/刷吧/.workbuddy/tmp/probe'
os.makedirs(tmp, exist_ok=True)
for ext in ['', '-wal', '-shm']:
    p = src + ext
    if os.path.exists(p):
        shutil.copy(p, tmp + '/shuaba.db' + ext)
con = sqlite3.connect(tmp + '/shuaba.db')
con.row_factory = sqlite3.Row
cur, cur2 = con.cursor(), con.cursor()   # 两个游标，避免嵌套查询重置
# ... 分析 ...
con.close()
# 清理
for f in os.listdir(tmp):
    try: os.remove(os.path.join(tmp, f))
    except: pass
os.rmdir(tmp)
```

## ⚠️ 表结构陷阱（踩过的坑）

| 坑 | 说明 |
|---|---|
| **`attempts` 时间字段是 `attempted_at`** | **不是 `created_at`** |
| **`attempts` 没有 `self_summary` / `note`** | 别查这两列 |
| **`outcome` 有 `wrong` 和 `incorrect` 两种错值** | **以 `outcome` 为准**，统计时两种都要算 |
| `duration_seconds` 单位是**秒** | 脏数据：`#2045` 一次 4613s、`#994` 一次 34811s（计时没关）。有效区间建议 `[5s, 1200s]` |
| `difficulty_multiplier` 在 **`attempts`** 上 | `questions` 上只有 `difficulty` |
| `evidence_source` 可信度 | `codex` > `manual_confirmed` > `self_report` > `legacy` |
| `recommendation_batches` **没有 `id` 列** | 主键是 `task_id` |
| `recommendation_batch_items` 排序列叫 **`position`** | 角色列叫 **`role`**（不是 `question_role`）；`recommendation_order` 字段**不存在** |

## ⚠️ 统计口径坑

**用 `like '%向量%'` 之类模糊分组会把不同板块串在一起。**
例：方程组下含「向量」二字的子类（已知向量关系求通解 / 已知解向量的线性组合求通解 /
无关解向量的个数）会被串进「向量」板块。

**必须按完整 `category_path` 精确分组。**
线代二级板块的真实名称（注意不是「特征值与相似」）：

```
线性代数 / 矩阵              202 题 / 29 叶子
线性代数 / 线性方程组         190 题 / 34 叶子
线性代数 / 特征值与特征向量    165 题 / 18 叶子   ← 叫「特征值与特征向量」，不是「特征值与相似」
线性代数 / 二次型            149 题 / 17 叶子
线性代数 / 行列式            121 题 / 13 叶子
线性代数 / 向量             102 题 / 12 叶子
线性代数 / 数学一专项          29 题 /  1 叶子   ← 注意只有 1 个叶子
```

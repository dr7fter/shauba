# .agent/ · Agent 分册地图

> 这些是从 `AGENTS.md` 拆出的**低频但重要**的规格，加上新增的纪律文档。
> **不要全读**——按任务类型读对应的那一份。路由见 `AGENTS.md` 的路由表。

| 文件 | 什么时候读 | 大小级别 |
|---|---|---|
| `01-回传格式.md` | 向 App 写 JSON（推题 / 批改 / 作战计划） | 中 |
| `02-批改与诊断.md` | 批改草稿 | 中 |
| `03-评分与ELO.md` | 调评分参数 / 做评分相关开发 | 大 |
| `04-发版流程.md` | 发版、打 tag、传 Release | 中 |
| `05-数据库与查询纪律.md` | **任何查库分析** | 大 |
| `06-AI闭环通道.md` | **任何"AI 接入 / 自动化"提案**；搞不清批改报告存在哪 | 大 |
| `07-取样与备考.md` | 检阅题库挑题、排备考计划、评定外部方案 | 中 |
| `08-产品约束摘录.md` | 改学习引擎 / 选题逻辑 / 错误处理；想知道历史版本定下的规矩 | 中 |

## 优先级建议

- **查库分析** → 先 `05`，再看要不要 `07`
- **推题** → `07`（取样策略 v5）→ `01`（回传格式）
- **批改** → `02` → `01`
- **提"AI 接入"方案** → **先 `06`**，它会告诉你闭环已经有了
- **发版** → `04`

## 维护约定

- 分册内容变更时在文件头更新日期
- **AGENTS.md 只放红线 + 路由表**，不放具体规格——它一旦超过 6KB 就会在上下文注入时被截断
- 新增分册时同步更新本表和 `AGENTS.md` 的路由表

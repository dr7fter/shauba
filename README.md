# 刷吧

独立、数一专用、纸笔优先的本地刷题桌面 App。

## 当前能力

- 从 `E:\考研资料\题库-大观园` 导入数一题目与图片，题库源保持只读
- 固定题数、固定时长或双目标训练
- 纸上作答、选择题判定、四档自评与间隔复习
- 可解释的本地推荐队列
- Codex 草稿批改任务与 JSON 收件箱
- Codex 推荐题目覆盖队列
- 题库筛选、错题复习、AI 批改确认和学习洞察

## 开发

```powershell
npm install
npm run app
```

仅浏览器预览：

```powershell
npm run dev -- --port 1420
```

浏览器预览使用样例数据，Tauri 桌面运行时自动导入完整本地题库。

## 数据边界

- 题库：`E:\考研资料\题库-大观园`，只读
- 刷吧数据库：系统应用数据目录中的 `shuaba.db`
- Codex 回传：系统应用数据目录中的 `codex-inbox`

Codex 回传协议见 `AGENTS.md`。

## AC-P1 主环可用性（Sprint B）

### AC-P1-1 主观题必须先判定再记录

**Given** 主观题已揭示  
**When** 只选流畅度 4、不选做对/部分/做错/不确定  
**Then** 「记录并继续」保持 disabled。选「不确定」后可提交，attempts.outcome=`uncertain`，progress 不更新，UI 不得显示「❌ 错误」。

### AC-P1-2 今日完成数不含 uncertain

**Given** 当天有 1 条 uncertain、7 条 scored  
**When** 看今日进度和顶栏  
**Then** 完成数为 7（或单独标注 7 记入 + 1 诊断），与 Insights 口径一致。

### AC-P1-3 只有一个作答钟

**Given** 开始做题  
**When** 完成本题并提交  
**Then** `attempts.duration_seconds` 等于题内钟结算值（1–1800）。顶栏钟若仍在，明确写「不计入统计」。

### AC-P1-4 复习间隔文案等于真实 SRS

**Given** 设置中间隔为 3/5/15/30  
**When** 评分 1 / 2 / 3 / 4 并提交正确或错误  
**Then** 界面显示的下一复习日与 `progress.next_review` 一致，不再写死「明日 / 3 天后」。

### AC-P1-5 Codex 只有 inbox 一条路

**Given** 一组纸笔草稿  
**When** 用户要整组批改  
**Then** 只能生成 `SB-BATCH-...` 任务，结果进入 `codex-inbox`，确认后写 attempts。不存在「粘贴 JSON 到压力框」的主路径。

### AC-P1-6 每日默认顺序可读

**Given** 有到期题、有错题、有新题  
**When** 打开今日且没有自定义队列  
**Then** 队列理由按「到期复习 → 薄弱修复 → 新覆盖」排序或分组，用户不用猜先做什么。

### AC-P1-7 小窗能点到主 CTA

**Given** 窗口 840×620  
**When** 进入未揭示题目  
**Then** 「我已完成 / 查看答案」无需滚动即可点到（或题干区有固定底栏）。

### AC-P1-8 闪击战不再伪装成主考试

**Given** 今日页  
**When** 用户扫一眼入口  
**Then** 至多保留一个「考试/模拟」主入口。另一个降级到命令菜单或设置实验项，文案不出现两个「高压」。

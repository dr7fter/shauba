## 📦 v1.0.0 实施范围

### P0 目标（必须完成）

#### 1. Rust 后端三层架构重构

**当前架构问题**（src-tauri/src/lib.rs）：
```rust
// 当前：所有逻辑混在 lib.rs，约 800+ 行
#[tauri::command]
fn create_session(...) { /* SQL 直接写在这里 */ }
#[tauri::command]
fn load_problems(...) { /* 业务逻辑与数据访问耦合 */ }
```

**目标架构**：
```
src-tauri/src/
├── lib.rs (100 行 - 仅 Tauri 命令注册)
├── commands/ (300 行 - Tauri 命令层)
│   ├── session.rs
│   ├── problem.rs
│   ├── review.rs
│   └── settings.rs
├── services/ (400 行 - 业务逻辑层)
│   ├── session_service.rs
│   ├── problem_service.rs
│   ├── review_service.rs
│   └── srs_engine.rs
└── db/ (200 行 - 数据访问层)
    ├── mod.rs
    ├── session_dao.rs
    ├── problem_dao.rs
    └── review_dao.rs
```

**拆分步骤**：
1. 创建 `db/` 模块，提取所有 SQL 查询
2. 创建 `services/` 模块，提取业务逻辑
3. 创建 `commands/` 模块，重构 Tauri 命令
4. 更新 `lib.rs`，仅保留命令注册

**验收标准**：
- lib.rs < 100 行
- 每个 Tauri 命令 < 20 行（仅调用 service）
- 所有 SQL 查询在 `db/` 模块
- 所有业务逻辑在 `services/` 模块
- Rust 测试覆盖率 > 80%

#### 2. CSS Modules 全面迁移

**当前问题**：
- 全局 CSS 类名冲突风险
- `src/App.css` 过大（1500+ 行）
- 样式耦合，难以维护

**目标架构**：
```
src/
├── App.module.css (< 300 行 - 全局布局)
├── components/
│   ├── KeyboardHelpModal.tsx
│   ├── KeyboardHelpModal.module.css
│   ├── FormulaDrawer.tsx
│   ├── FormulaDrawer.module.css
│   └── ...
└── views/
    ├── TodayView.tsx
    ├── TodayView.module.css
    └── ...
```

**迁移步骤**：
1. 为每个组件创建 `.module.css`
2. 提取组件专属样式到模块文件
3. 更新组件导入：`import styles from './Component.module.css'`
4. 替换类名：`className="card"` → `className={styles.card}`
5. 保留全局样式在 `index.css`（CSS 变量、reset、typography）

**验收标准**：
- App.css → App.module.css，< 300 行
- 每个组件/视图有独立 `.module.css`
- 无全局类名冲突
- 所有 CSS 变量保留在 `index.css`

#### 3. 浅色主题实现

**实现方案**：

**1. 扩展主题系统**（src/types.ts）：
```typescript
export type Theme = 'dark' | 'light' | 'auto'

export interface UserSettings {
  theme: Theme // 新增
  zenMode: boolean
  // ...
}
```

**2. 定义浅色主题色板**（src/index.css）：
```css
:root {
  /* 深色主题（默认） */
  --bg-primary: #0A0D12;
  --bg-secondary: #0F131C;
  --text-primary: #E5E7EB;
  --accent: #38BDF8;
}

[data-theme="light"] {
  /* 浅色主题 */
  --bg-primary: #FFFFFF;
  --bg-secondary: #F9FAFB;
  --bg-tertiary: #F3F4F6;
  --text-primary: #111827;
  --text-secondary: #6B7280;
  --accent: #2563EB;
  --accent-hover: #1D4ED8;
  --border: #E5E7EB;
  --shadow: rgba(0, 0, 0, 0.1);
}
```

**3. 主题切换逻辑**（src/App.tsx）：
```typescript
useEffect(() => {
  const theme = settings.theme
  if (theme === 'auto') {
    const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches
    document.documentElement.setAttribute('data-theme', prefersDark ? 'dark' : 'light')
  } else {
    document.documentElement.setAttribute('data-theme', theme)
  }
}, [settings.theme])
```

**4. 设置页面增加主题选择器**（src/views/SettingsView.tsx）：
```tsx
<select value={settings.theme} onChange={e => updateSettings({ theme: e.target.value })}>
  <option value="dark">深色</option>
  <option value="light">浅色</option>
  <option value="auto">跟随系统</option>
</select>
```

**验收标准**：
- 支持深色/浅色/自动三种模式
- 所有组件在浅色主题下可读性良好
- 无硬编码颜色值（全部使用 CSS 变量）
- 主题切换无闪烁

#### 4. 性能优化

**4.1 题库列表虚拟滚动**

**问题**：题库列表渲染 100+ 题目，初始加载卡顿

**方案**：引入 `react-window`
```tsx
import { FixedSizeList as List } from 'react-window'

<List
  height={600}
  itemCount={problems.length}
  itemSize={80}
  width="100%"
>
  {({ index, style }) => (
    <div style={style}>
      <ProblemCard problem={problems[index]} />
    </div>
  )}
</List>
```

**4.2 图片懒加载**

**方案**：使用原生 `loading="lazy"`
```tsx
<img 
  src={imagePath} 
  loading="lazy"
  alt={problem.title}
/>
```

**4.3 代码分割**

**方案**：React.lazy + Suspense
```tsx
const StatsView = lazy(() => import('./views/StatsView'))
const ReviewView = lazy(() => import('./views/ReviewView'))

<Suspense fallback={<LoadingSpinner />}>
  <Routes>
    <Route path="/stats" element={<StatsView />} />
    <Route path="/review" element={<ReviewView />} />
  </Routes>
</Suspense>
```

**验收标准**：
- 题库列表滚动帧率 > 50 FPS
- 首屏加载时间 < 1.5 秒
- 图片延迟加载生效
- 路由级代码分割生效

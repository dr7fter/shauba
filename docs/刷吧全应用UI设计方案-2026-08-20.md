# 刷吧全应用 UI 设计方案

> 日期：2026-08-20。基线：当前代码 `src/App.tsx`（3,789 行）、`src/App.css`（4,967 行）、`src/components/*`。
> 本方案取代《刷吧改进建议》《第二轮》《第三轮》与 vNext 需求报告中的视觉章节；与现状相符的部分（如四档窗口验收）被吸收进本方案。

## 1. 现状结论：没有 app 级设计系统

现在存在的是"按功能堆叠"的样式表，不是系统。视觉底子（淡绿、纸感、卡片化、安静）值得保留，问题在于缺少收敛层，每加一个功能就漂一次。

证据（全部取自当前源码）：

| 维度 | 现状 | 问题 |
|---|---|---|
| 颜色 | App.css 仅 9 个 CSS 变量、index.css 少量补充，var() 使用 793 次；但变量之外另有 **403 个硬编码 hex + 98 个 rgba** | token 存在但不约束，同一种"绿/灰/黄"有多种写法 |
| 字体 | 406 处 font-size、**28 种取值**、全部 px；12px×122 / 11px×106 / 13px×65 / 10px×48 为主，另有 9px 与小数 px（10.5/11.5/12.5/15.5） | 无字号阶梯；正文普遍 10–12px，低于可读底线 |
| 字号缩放 | `data-font-scale` 三档只改 root font-size（14/15.5/17px） | 对 406 处 px 声明**基本无效，功能形同虚设** |
| 圆角 | 19 种 border-radius（2–12 的整数几乎齐了） | 无圆角阶梯 |
| 阴影 | 70 种 box-shadow | 无海拔层级 |
| 结构 | **108 个重复选择器**（`.topbar h1`、`.queue-item`、`.mastery-grid` 等 13 个被定义 3 次）、**37 个 !important** | 后补丁压前补丁，顺序依赖，不敢删 |
| 断点 | 7 个 media：1240/1180/1050/960/840/700 + max-height 720 | 断点泛滥、互相重叠 |
| 组件 | 无 `.btn`/`.card`/modal 基类；5 个弹窗各自造 overlay/容器/关闭按钮（`battle-report-overlay` vs `contract-modal-overlay` vs …） | 同一模式实现 5 遍，度量各异 |
| 主题 | light/warm/dark/system 四模式；warm/dark 只覆盖约 9 个变量 + 少量组件级硬编码补丁 | 几百个硬编码色不跟主题走 → 暗色必然不完整，打地鼠式修补 |
| 布局 | today/review/insights 双列卡片、settings 单列分组卡、library 表格行；顶栏承载 6+ 功能入口（公式/战报/禅/纯净/D-day/游戏中心） | 无页面骨架契约，顶栏持续膨胀 |
| 死文件 | `src/App.css.reconstructed` 未被任何地方引用 | 历史审计残留 |

类名前缀统计：141 个前缀、1,303 条规则（review×154、mastery×50、topbar×40、game×25、blitz×23、contract×20……），每个功能一个独立王国。

## 2. 设计原则

1. **保住身份**：纸感、安静、可信、轻微仪式感；淡绿主色、卡片化——不改视觉底子，只补收敛层。
2. **语义用色契约**：绿 = 继续/完成/可信正确；红 = 错误/危险操作；琥珀 = 到期/注意；蓝 = AI/信息；金 = 仅游戏中心内部，不进主训练界面。
3. **颜色全部进 token**：组件样式只引用语义变量；`[data-theme]` 只覆盖 token 值，不写组件级补丁。
4. **可读底线**：正文 ≥ 13px，元信息 ≥ 11px，消灭 9/10px 正文；题干独立大档。
5. **一个模式一个实现**：modal、button、card、badge、空态、toast、表单行、表格行各只有一个基类实现。
6. **不重写功能**：收敛全部在样式层替换，不碰业务逻辑；每个 Sprint 结束保持 `npm run build` 绿。

## 3. Token 层（新增 `src/styles/tokens.css`）

### 3.1 颜色

表面层：`--canvas`（页底）/ `--surface`（卡片）/ `--sunken`（凹陷底）/ `--ink` / `--muted` / `--quiet` / `--line`。

状态色（各带 `-soft` 浅底变体）：`--success`（绿系）、`--warn`（琥珀系）、`--danger`（红系）、`--info`（蓝系）、`--gold`（仅游戏中心）。

现有高频值 → token 映射（按出现次数取头部）：

| 现值（次数） | 收敛到 |
|---|---|
| #fff / #ffffff（×128） | --surface |
| #e2e8f0 / #cbd5e1 / #e2ebe6 / #bad3c5 | --line |
| #f8fafc / #f1f5f9 / #eef3f0 / #f7faf8 | --canvas / --sunken |
| #94a3b8 / #64748b / #475569 | --muted / --ink |
| #d97706 / #f59e0b / #b45309 / #92400e / #fef3c7 / #fde68a | --warn / --warn-strong / --warn-soft |
| #2b7a5a / #1e362d | --success-strong / --ink-on-soft |
| #b91c1c / #a24f47 / #fee2e2 | --danger / --danger-soft |
| #2f6e91 / #2f627d | --info |

主题 = light / warm / dark 三套 token 值，`system` 跟随系统。**删除全部 `[data-theme="…"] .组件` 级补丁。**

### 3.2 字号阶梯

收敛为 9 档（覆盖现状 95%+ 用量），全部走变量，使 `data-font-scale` 真正生效：

| Token | standard | 用途 |
|---|---|---|
| --fs-xs | 11px | 元信息、徽章、辅助 |
| --fs-sm | 12px | 次级文本、表格行 |
| --fs-base | 13px | 正文、列表主文 |
| --fs-md | 14px | 强调正文、表单控件 |
| --fs-lg | 16px | 卡片标题 |
| --fs-xl | 18px | 页标题（topbar h1） |
| --fs-2xl | 22px | 数字强调 |
| --fs-stem | 20px | 题干（用户可调） |
| --fs-display | 28px | 战报/仪式场景 |

font-scale 三档改为对这组变量的整体倍率（×1 / ×1.1 / ×1.2），不再改 root font-size。

### 3.3 其余 token

- 间距（4px 基）：4 / 8 / 12 / 16 / 20 / 24 / 32 / 48。
- 圆角：--r-xs 4 / --r-sm 6 / --r-md 8 / --r-lg 12 / --r-full。
- 海拔：--shadow-1（卡片）/ --shadow-2（浮层、抽屉）/ --shadow-3（modal）；焦点环统一 2px `--ring`。
- 尺寸：控件高 --h-sm 28 / --h-md 36 / --h-lg 42；图标 16 / 18 / 20。
- 动效：--dur-1 120ms（状态）/ --dur-2 240ms（进出）；保留现有 `data-reduced-motion` 全局开关。
- z-index：内容 0 / topbar 10 / drawer 30 / modal 40 / toast 50。

## 4. 组件层（新增 `src/styles/ui.css` + `src/components/ui/*`）

命名统一 `ui-*`，从现有实现收敛：

| 基元 | 收敛来源（现状） |
|---|---|
| ui-button（primary/secondary/ghost/danger/icon） | 各功能自造按钮（绿色大按钮、topbar 按钮族、表格行内按钮……） |
| ui-card（+ ui-card-header） | history-card、trend-card、settings section、review 族卡片、radar/treemap 卡 |
| ui-modal（overlay/容器/header/关闭） | battle-report、contract、blitz、game、formula 五套自实现 |
| ui-badge / ui-pill | dday-pill、reason pills、状态徽章、pace pills |
| ui-stat-tile | poster-stats-grid、topbar 指标、insights 摘要卡 |
| ui-tabs / ui-segmented | GameCenter tabs、现有 segmented |
| ui-empty / ui-toast | EmptyState、Toast（已全局化，转正） |
| ui-form-row | 设置页表单行 |
| ui-table-row | 题库表格行 |

原则：基元只消费语义 token；组件内不允许出现 hex。

## 5. 布局层

### 5.1 骨架

- sidebar：宽屏 200px；<1050 收为图标栏（现有行为转正为契约）。
- topbar：固定 56px，**契约只留**：页标题（+副标题）、会话计时、通知、个人入口。公式、战报、禅模式、纯净模式、D-day、游戏中心入口移入命令菜单或页内工具栏。
- main：统一 `page-grid`。

### 5.2 页面网格与断点

- ≥1240：`1fr 340px` 双列；today/review/insights 维持现状，**settings 也进网格**（分组卡双列），library 全宽表 + 右侧详情。
- 960–1240：`1fr 300px` 双列。
- <960：单列；训练队列变抽屉、答案面板入题下（现有 mobile 行为转正）。
- **断点收敛为 1240 / 960 两档**（max-height 720 可选保留），删除 1180/1050/840/700。

### 5.3 视图节奏

每个视图 = 页头行（统一样式）+ 内容网格；指标卡统一 ui-stat-tile；长列表统一 ui-table-row + 分页。

## 6. 迁移路线（3 个 Sprint，只动样式层）

**Sprint A — token 收敛（1–2 天）**
1. 新增 `src/styles/tokens.css`，在 index.css 顶部引入。
2. 批量替换 top ~30 高频 hex 为变量（约覆盖 60% 硬编码出现次数）。
3. font-size 改 `var(--fs-*)`；font-scale 改倍率实现，修复失效功能。
4. 删除 `src/App.css.reconstructed`。
5. `scripts/` 加硬检查（tokens 之外的硬编码色、新增 !important），构建前跑。

**Sprint B — 组件收敛（2–3 天）**
1. ui-modal 统一 5 个弹窗/抽屉。
2. 收敛 ui-button / ui-card / ui-badge / ui-stat-tile / ui-tabs / ui-form-row / ui-table-row。
3. 清零 108 个重复选择器与 37 个 !important（按视图逐块删，行为不变）。

**Sprint C — 布局与验收（1–2 天）**
1. 落实 topbar 契约 + 命令菜单。
2. page-grid 统一五个视图；断点收敛。
3. 重拍 1440×900 / 1280×720 / 1024×768 / 840×620 视觉回归截图（复用现有截图管线）。

每个 Sprint 验收：`npm run build` 绿 + 截图对比无功能差异 + 第 7 节指标。

## 7. 验收指标（量化）

- tokens.css 之外 hex/rgba 硬编码 = 0。
- font-size 唯一值 ≤ 9；!important = 0；重复选择器 = 0。
- border-radius 唯一值 ≤ 5；box-shadow 唯一值 ≤ 3（+ring）。
- 组件级 `[data-theme]` 补丁 = 0；三主题切换无缺样式。
- font-scale 三档截图有可测量差异（功能真实生效）。
- 四档窗口：无中文竖排、主操作无横向滚动。

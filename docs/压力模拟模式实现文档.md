# 压力模拟模式实现文档

## 功能概述

压力模拟模式是刷吧应用中新增的一种考试模拟功能，旨在为用户提供真实的考试环境体验。

## 核心特性

### 1. 真实考试体验
- ❌ 不显示答案和解析
- ❌ 不能自评和修改答案
- ✅ 全部完成后由 Codex 批改
- ⏱️ 记录每题用时和总用时

### 2. 模式流程

```
启动模拟 → 逐题作答 → 完成提交 → Codex 批改 → 查看报告
```

#### 2.1 启动模拟
- 在队列面板点击"压力模拟"按钮
- 确认对话框显示题目数量和预计用时
- 至少需要 5 道题才能开启

#### 2.2 逐题作答
- 显示当前进度（X / 总题数）
- 显示剩余题数
- 显示总用时计时器
- 选择/填写答案后点击"下一题"
- 最后一题点击"完成并提交批改"

#### 2.3 批改流程
1. 完成所有题目后，系统生成批改任务
2. 复制批改任务到 Codex
3. Codex 返回 JSON 格式的批改结果
4. 粘贴批改结果并解析

#### 2.4 查看报告
- 总体得分和正确率
- 逐题批改结果（正确/错误标记）
- 每题的答案对比和批注
- 优势、待提升和建议总结

### 后端实现 (Rust)

#### 数据库表结构

```sql
-- 压力模拟会话表
CREATE TABLE pressure_sessions (
    session_id TEXT PRIMARY KEY,
    question_ids TEXT NOT NULL,  -- JSON 数组
    start_time INTEGER NOT NULL,
    end_time INTEGER,
    status TEXT NOT NULL,        -- 'ongoing', 'submitted', 'graded'
    created_at INTEGER NOT NULL
);

-- 答案记录表
CREATE TABLE pressure_answers (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id TEXT NOT NULL,
    question_id INTEGER NOT NULL,
    user_answer TEXT NOT NULL,
    duration INTEGER NOT NULL,
    submit_time INTEGER NOT NULL,
    FOREIGN KEY (session_id) REFERENCES pressure_sessions(session_id)
);

-- 批改报告表
CREATE TABLE pressure_reports (
    session_id TEXT PRIMARY KEY,
    report_json TEXT NOT NULL,
    created_at INTEGER NOT NULL,
    FOREIGN KEY (session_id) REFERENCES pressure_sessions(session_id)
);

-- 索引
CREATE INDEX idx_pressure_sessions_created_at ON pressure_sessions(created_at);
CREATE INDEX idx_pressure_answers_session ON pressure_answers(session_id);
```

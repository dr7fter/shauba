⚠ 最早断点 codex · 批改输出

落笔即设 x = sin²t，把 √(x+1) + √(1−x) 化为三角和式。但该结构分子分母的根号内 都是整式（含 1 是偏移，不是根号内分式），正确入口是整式换元 t = √(x+1) 化简后再做对称性，而非三角换元。你在 1′55″ → 0′53″ 的复习中重复了同一条路径—— 耗时缩短带来的是"路径熟练度"，不是"路径正确性"。

标准解法（codex 推荐路径）

第 1 步 · 入口识别：分子分母都是 √(整式)，未出现分式嵌套 → 排除三角换元 → 用整式换元 t = √(x+1)。

第 2 步 · 化简：令 t² = x+1，则 dx = 2t dt，原式化为 ∫ t / (t + √(2−t²)) · 2t dt。

第 3 步 · 对称性秒杀：分子含 t² 时与分母 √(2−t²) 不对称，改设 t = √((1+x)/2)·√2，把区间 [0,1] 映射到 [1,√2]，配合 x ↔ 1−x 对称可省一半运算。

第 4 步 · 出口：由 I = ∫₀¹ f(x)dx 且 f(x) + f(1−x) = 1 直接得 I = 1/2。

考场专项抢救指令

本类题的否定式规则："看到根号内为整式（无论含不含 1、a、x）→ 禁止直接上三角换元 → 先做整式换元 t = √(整式)，再判断能否走对称性"。

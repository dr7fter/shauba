## 四、唯一没修好的那条线

`#143` 与 `#147` 是**同一个断点的两个面**。

| | #143 | #147 |
|---|---|---|
| 结构 | $A^n=O$，求 $(E-A)^{-1}$ | $B=(E+A)^{-1}(E-A)$，求 $[(E+B)^2]^{-1}$ |
| 正确动作 | $(E-A)(E+A+\cdots+A^{n-1})=E-A^n$ | $E+B=2(E+A)^{-1}$，提取公因式 |
| 实际 | 草稿「没思路啊」，**4′29″ 放弃** | 硬算 $(E+A)^{-1}$，**8′02″ 只拿 partial** |
| 共同点 | **都没有在动笔前先化简** | |

### 病灶性质修正：不是不会，是不敢用

看你自己写的复盘原话——

> #143「我见过这个公式，但是我感觉我的熟练度很低，**我应该很难自己去使用它**」
> #147「这个应该主要就是矩阵的一种运算吧，我感觉这个运算**可能我确实不太熟悉**」
> #274「我记得行向量跟列向量的线性表示是有一点不一样的，但是我**不是特别清楚，有点记不清楚了**」

三句全是同一个句式：**「见过 / 记得有这回事 / 但不确定自己能不能主动用」**。

这跟「没学过」是两回事，所以修复方式也不同：

| | 检索不出方法 | 见过但不敢用 |
|---|---|---|
| 缺什么 | 缺知识 | 缺**调用信心** |
| 怎么补 | 讲一遍 | **强制调用**，逼自己上手 |
| 再讲一遍有用吗 | 有用 | **没用** |

**证据**：我在开练速查里把 #143 的完整公式 $(E-A)^{-1}=E+A+\cdots+A^{n-1}$ **直接写在面前了**，
结果还是「没思路」。把答案摆在眼前都调不出来，就说明问题不在知不知道。

### 顺带：两种失败的应对模式，都错

- **抽象无数字**（#143）→ 4′29″ 写「没思路」**快速放弃**
- **有具体数字**（#147）→ 8′02″ **硬算死磕**

缺的是第三种反应：**停下来，先对这个式子做代数变形**。

### 动笔前 10 秒的「能不能先化简」检查

看到下面这类**矩阵代数复合式**，先停 10 秒问一句「这个式子能不能先化简」，**再动笔**：

$$A^n=O \quad/\quad (E+A)^{-1}(E-A) \quad/\quad E-\alpha\alpha^{\mathrm{T}} \quad/\quad AB-A-B \quad/\quad (E+A)^{-1}+(E-A)^{-1}$$

判据：**如果动笔后要算 3 阶以上的矩阵乘法或求逆，那大概率是路走错了。**
本组 #147 就是硬算 $(E+A)^{-1}$ 时崩的；#204、#144 都是化简后 3 分钟内解决的。

这条不是知识，是**习惯**，要练到变成肌肉记忆。

**这条解释了一个反复出现的现象**：只要「优先选选择题省时间」+「不想上 d=3 太难」，

**破解方法**：要难度梯度又想控时间，就**用 d=1 选择 + d=3 选择混搭**，

## 二、九个场景的完整规格

### 场景 1 · 侦察卷（Recon）

**触发**：某块覆盖 < 20%，或完全零覆盖，不知道底数。

**目标**：用最小样本建立正确率基线，判断这块是「有底子」还是「断点区」。

**取样**：
1. 用**严格前缀**统计该章题量（如 `线性代数 / 矩阵%`，不是 `%矩阵%`——后者会串进别的章）
2. 列出题量 ≥ 8 的主干叶子，按题量排序
3. **每个叶子取 1 题**，优先选择题
4. 排序按**认知负荷递增**：基本型热身 → 概念与参数 → 综合题压轴

**题量 / 难度 / 时间**：8–12 题；中等档（建议 d1:d2:d3 ≈ 4:4:2）；约 40–55′。

**给不给答案**：**不给。** 给了就污染诊断——你无法区分「想起来了」和「本来就会」。

**判据**（正确率三档）：
- **≥ 70%** → 有底子，该叶子转间隔复习，不必再侦察
- **40–70%** → 正常，下一轮同叶子再取 1 题确认
- **< 40%** → 判为断点，转场景 3 修复卷

**装不下的分类**：必须写**补测清单**（含题号），下一轮补测，不许悄悄略过。

**坑**：
- 拿「识别即秒杀」挑侦察卷 → 会漏掉整块没测到的分类
- 全取 d=1 → 正确率虚高，得出错误结论
- 连续 id 段全落同一叶子（见 §3.3）

**实例**：2026-08-30 A1 极限侦察卷 15 题 → 93%，据此判极限直进强化、不回炉。

---

### 场景 2 · 补漏卷（Patch）

**触发**：覆盖 20–60%，主干已测过，要横向扩面。

**与侦察卷的区别**：侦察卷测的是**主干**（题量大的），补漏卷测的是**还没碰过的**，
包括那些题量小、低频但会考的叶子。

**取样**：
1. 列出该章**全部叶子**，减去已覆盖的
2. 未触及叶子各取 1 题，按分值权重排序取前 N 个
3. 若未触及叶子太多（> 12），按「该叶子题量 ≥ 5」+「数一考纲内」先筛一轮

**题量 / 难度 / 时间**：8–12 题；中等档；约 40–55′。

**给不给答案**：不给。

**判据**：**覆盖率增量**，不是正确率。
目标是把该章叶子覆盖率推到 60% 以上，再谈别的。

**坑**：
- 别用「加新题扩大覆盖」来回应「方法入口检索失败」这个病灶——那是场景 3 的事，
  用补漏卷治它会导致「用题量掩盖不消化」（2026-08-29 前例：正确率 43%→33%，日题量 8→27）

---

### 场景 3 · 修复卷（Repair）

**触发**：已确认具体断点——有题号、有错因、有错法。

**目标**：把「识别动作」刻进去，不是把题做对。

**第一原则**（针对核心病灶「方法入口检索失败」）：

> 每题必须有且**只有一个**「**识别即秒杀、不识别即硬算**」的关键动作。

**必须排除**（哪怕考点相关、在候选列表里）：
- 只换数字的同构题
- 与已固化题同族、套标准套路就能过的题
- 需要大量计算才能验证、却没有捷径可识别的题

**取样**：围绕断点做**变式**——改变条件 / 改变表示 / 改变入口，让识别动作必须重新走一遍。

**题量 / 难度 / 时间**：5–7 题；刻意改变难度形态；约 25–40′。

**给不给答案**：**给。** 重点在识别动作，不在算到底。

**判据**：**动笔 30 秒内写出关键识别动作**；做完口述「识别到什么结构 → 对应什么动作」。
**说不出来 = 白做。**

**三种「做不对」的修法完全不同**（先诊断再选动作）：

| 类型 | 表现 | 修法 |
|---|---|---|
| 知识缺口 | 不记得公式/定理 | 讲一遍 |
| 见过不敢用 | 记得但不确定能不能主动调 | **逼着调用**（讲一遍没用） |
| **错误路径固化** ⚠️ | 复习时**错得比第一次还快** | **用否定式规则在入口拦截旧路径** |

错误路径固化的识别信号：**复习耗时低于首次，且结果照错**（如 #7076 115s→53s、
#10590 677s→57s）。它伪装成「我会做」，最危险。
修法关键：**否定式**——「看到 X **禁止**做 Z」，而不是「看到 X 应该做 Y」。

**坑**：
- 拿「覆盖面取样」挑修复卷 → 浪费时间在已固化的题上
- 用肯定式规则修错误路径固化 → 会被旧习惯覆盖

---

### 场景 4 · 验收卷（Verify）

**触发**：修复卷做完后，要确认是不是真修好了。

**目标**：确认内化，不是再练一遍。

**取样**：**原题重做，绝不出新题。** 新题测不出「这道题的动作是否刻进去了」。

**题量 / 难度**：2–5 题（就是上一轮错的那几道）；同原题。

**给不给答案**：给（已修复的动作，不需要再考识别）。

**判据**：**耗时降到首次的 1/3 以下。**

| 题 | 首次 → 复习 | 判定 |
|---|---|---|
| #10587 | 808s → 451s → **45s**（1/18） | ✅ 真内化 |
| #10578 | 105s → **12s** | ✅ 真内化 |
| #7090 | 723s → **191s**（1/4） | ✅ 修好 |
| #1052 | 1257s → 656s（只降一半） | ❌ 假掌握 |

**「做对了」不等于掌握。看耗时的数量级变化，不看对错。**

**未通过的处理**：回文档再「学」一遍，**不推进新题**。
判定为「概念型缺口」（题次 ≥4 且正确率仍 <40%）时尤其如此——刷题解决不了，必须先讲透。

---

### 场景 5 · 复习卷（Review）

**触发**：`progress.next_review` 到期。

**目标**：抗遗忘，把「见过」推成「会做」。

**取样**（优先级严格排序）：
1. 最后一次作答为**错**的（incorrect + wrong）
2. 最后一次作答为 **partial** 的
3. `mastery < 50` 的优先
4. 同为错题时，按「首次耗时」降序（耗时长的说明当时投入大，流失代价高）

> **口径警告**：`outcome` 有 `wrong` 和 `incorrect` 两种错值，**必须合并归一**；
> 不要用 `result` 字段（语义与 `outcome` 分叉）。

**题量 / 时间**：每天 **8 题 / 约 28′**，匀速清仓。
（2026-09-01 到期积压 80 题，按此速度约 10 天清完。）

**判据**：同场景 4——**耗时数量级变化**。

**坑**：
- 只做新题不回炉 = 每次都停在「见过」这一层，两头漏
- 复习卷塞进新题 = 变成场景 2，失去抗遗忘功能

---

### 场景 6 · 强化卷（Intensify）

**触发**：某章侦察/补漏后正确率 ≥ 70%，要验是真掌握还是「章节内熟练」。

**目标**：把「在这章的简单题上正确率高」升级为「在真题难度上仍然稳」。

**取样**：
1. 该章 `difficulty = 3` 的题（共 1265 题可用）
2. **历年真题里该章的题**（420 道，2004–2026 数一，`category_path` 为 `历年真题/数一`）
3. 变式：改变条件 / 改变提问角度

**题量 / 难度 / 时间**：6–10 题；**高**（d3 为主）；约 40–60′。

**给不给答案**：不给。

**判据**：真题难度下 **仍 ≥ 70%** → 封盘，转间隔复习；
**< 70%** → 说明之前的高正确率是题型熟悉造成的，回场景 3 定位断点。

**实例**：极限章 15 题 93%（但全是 d1 档），待上强化档再验——目前**未封盘**。

---

### 场景 7 · 综合卷（Integration）

**触发**：两章以上已达标，要练跨章迁移。

**目标**：在没人提示「这题用哪章方法」的情况下，自己选对工具。

**取样**：跨章综合题（真题中的综合大题是最优来源，`历年真题/数一` 420 题）。
典型跨章组合：线代 × 空间解析（二次曲面）、一元积分 × 微分方程、级数 × 微分方程、
二重积分 × 多元微分。

**题量 / 难度 / 时间**：5–8 题；中高；约 40–55′。

**判据**：能否**自己**建立章与章的联系，不看提示做出来。

---

### 场景 8 · 真题卷（Paper）

**触发**：阶段三（一般 10 月后），或某章需外部验证。

**取样**：**420 道历年真题原卷**（2004–2026 数一，每年 10–31 题，共 29 个分类）。
按年份整套抽，不做挑选。

**特殊价值**：题库盖不住的三重积分 / 曲线曲面积分 / 空间解析几何（约 15–20 分），
**真题里必然有**。刻意统计这些考点的命中与得分，就能补上缺口，不必另找习题集。

**判据**：得分率 + **缺口考点命中率**（后者比前者更重要）。

---

### 场景 9 · 压力卷（Timed）

**触发**：离考试 < 60 天，或需要练速度/止损纪律。

**取样**：中等档（d1–d2 混合，不要用 d3——限时下 d3 只会逼出瞎猜），可控题量。

**题量 / 时间**：8–12 题，**限时**（按 §4.1 预算 × 0.7 压缩）。

**判据**：单位时间得分 + **止损执行率**（有没有真的在 8 分钟停手）。

## 三、通用前置检阅（所有场景必做的 7 步）

### 3.1 严格前缀统计
`高等数学 / 级数%` 是 440 题；`%级数%` 会把微分方程、一元微分里的「级数」子类串进来。
**统计章节题量必须用前者。**

### 3.2 剔除同名不同章
搜「二重」命中 265 题，其中 9 题属微分方程、5 题属极限的 n 项和。逐个核对 `category_path`。

### 3.3 跨类去重 ⚠️ 最容易翻车的一步
把 `stem` 做 LaTeX 归一化（去 `\displaystyle` / `\left` / `\right`、`\dfrac`→`\frac`、去空白）
再比哈希。二重积分里揪出过 8 组跨类重复（如 2987≡3886、2991≡3765）。

**去重之后还要查 id 连续性**：如果一组题的 id 是连续段（如 #3107–#3113），
**几乎必然全落在同一叶子**——这是「按 id 顺序扫」的典型痕迹，必须打散重取。

### 3.4 剔除「待统一删除」标记
当前 10 题。题干含【待统一删除…】。

### 3.5 核对答案完整性
当前全库 0 题缺失，但**新选题仍要逐题核**（`correct_answer` 与 `explanation` 均非空）。

### 3.6 核对已做题次
`attempts` 表按 `question_id` 查。全库重做率 1.38 次/题，避免把做过的题当新题推出去。

### 3.7 叶子分布核算
**统计「题数 / 不同叶子数」**。侦察卷与补漏卷应 ≈ 1.0–1.5；
超过 2.5 就是塌缩，打回重取。

## 四、时间与容量换算

### 4.1 耗时预算表（codex 源实测，n=180）

| 题型 \ 难度 | d1 | d2 | d3 |
|---|---|---|---|
| **单选** | 2.3′ | — | 3.4′ |
| **主观** | 4.4′ | 5.2′ | 6.5′ |

实测均值：单选 **2.7′**、主观 **5.2′**（n=38 / n=142）。
难度均值：d1 3.2′ / d2 4.7′ / d3 6.4′。

**推论**：覆盖同样一个叶子，用选择题省约一半时间（且正确率高 10 个百分点：
65% vs 55%）。**能用选择题顶替的就用选择题**——
二重积分组用 7 道选择题顶掉 7 道主观题，省约 40 分钟且覆盖零损失。

### 4.2 日容量锚定 **111′**

实测五日（8/27–8/31）：119 / 158 / 94 / 128 / 55，**均值 111′**。

### 4.3 止损线（硬数据支撑）

| 耗时 | 题数 | 正确率 | 半成品率 |
|---|---|---|---|

## 五、五条硬规则（违反即打回重做）

### 规则 1 · 单叶子抽取上限
| 叶子题量 | 单卷上限 | 单轮上限占比 |
|---|---|---|
| 1–9 题 | **1 题** | ≤ 25% |
| ≥ 10 题 | 2 题 | ≤ 25% |

理由：`正态分布 / 标准化` 全库只有 8 题，外部方案一次抽走 7 题 = 87.5%，
该叶子后续再无可取样空间。**看「题数/叶子数」比值，> 2.5 即塌缩。**

### 规则 2 · 难度不能清一色 d=1
一卷内必须含 d2 或 d3。
**注意选择题没有 d2**，要梯度就混搭 d1 选择 + d3 选择，或接受少量 d2 主观题。

### 规则 3 · 侦察卷与补漏卷不给答案
给了就分不清「想起来了」和「本来就会」，整卷诊断作废。

### 规则 4 · 修复卷每题必须有且只有一个「识别即秒杀」动作
不识别即硬算。说不出识别动作 = 白做。

### 规则 5 · 任何一天的排产必须留复习位
到期复习按 **8 题 / 28′** 占位，先扣掉再排新题。
**只做新题 = 前面投入的时间在持续流失。**

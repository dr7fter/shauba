# 刷吧取样策略 v4：最小有效剂量 + 反馈驱动

> **版本**：v4 · 2026-09-01  
> **定位**：融合 v1 系统化、v2 容量控制、v3 个性化的务实方案  
> **核心原则**：最小有效剂量 → 快速反馈 → 动态调整

---

## 零、三条铁律（不可违背）

### 铁律 1：时间是硬约束，题量是软指标
- 实测日容量：**111 分钟**（近5日均值）
- 排产上限：**90 分钟 / 20 题**（留 20 分钟缓冲）
- 单题止损：选择题 **3.5 分钟**，主观题 **8 分钟**
- **宁可少做题做透，不可多做题做飘**

### 铁律 2：复习债务优先于新题扩张
- 当前积压：**80 题到期**（50 题错、18 题 partial）
- 每日必保：**8 题复习位**（约 28 分钟）
- 清偿周期：10 天内清零
- **只做新题 = 狗熊掰棒子，前功尽弃**

### 铁律 3：每道题必须回答"为什么是它"
- 不推"顺手的题"，只推"该测的题"
- 推题前必答三问：
  1. **本次测什么动作**？（触发/选路/执行/迁移/节奏）
  2. **为什么选这道**？（与已做题的差异在哪）
  3. **做成什么样算通过**？（量化判据 + 退出条件）
- **说不清就不推**

## 一、你的个性化画像（来自 352 次作答记录）

### 1.1 你的王牌能力
- **结构识别**：全微分消元、降维、算子、相似不变量、分块结构、Riemann 和式、交换次序——一旦认出骨架，速度和严密性同时上来
- **追问本质**：会问"最早哪一步错""为什么成立""有没有更短路径"
- **高负荷耐受**：能承受长步骤和高难度，不靠刷同构题找安全感

### 1.2 你的高危断点
- **含根式积分**（Level 1 断点）：根号出现时条件反射到三角换元，整体换元/倒代换入口未形成候选集
- **抽象矩阵代数式**：知道公式但动笔前未调用，被硬算拖住
- **拉格朗日/闭区域边界**：内部推导不差，丢分在"最后一个必须闭环的动作"
- **错误路径自动化**：复习时"更快地错"（如 #7076 115s→53s）——旧习惯变顺手，伪装成"我会了"

### 1.3 你的训练单位：五个可观察动作
不用"正确率"一刀切，而是分别记录：
1. **触发**：看到题面能否说出值得检查的结构
2. **选路**：能否在候选方法中排除错误入口
3. **执行**：代数、符号、边界、回代是否准确
4. **迁移**：换变量/换问法后动作是否仍出现
5. **节奏**：考场预算内完成，卡住时能否止损

## 三、六个核心场景（按使用频率排序）

### 场景 A：入口修复（最高频）
**触发**：已知具体断点（如含根式换元、抽象矩阵化简、算子链）

**目标**：刻入"识别动作"，不是刷题量

**取样规则**：
- **每题只承载一个主入口**，3-5 题形成"识别→执行→换壳"链：
  1. 题面结构明显，确认能叫出入口
  2. 同一入口换数字/表达，确认不是背题
  3. 放入干扰入口，要求先写"为什么不选另一条路"
  4. 换外观但保留同一不变量，测试迁移
- **刻意加入"看起来像旧错路"的干扰题**——错误路径被拦住比解出熟题更有价值

**作答要求**：先写一句入口判断，再开始计算

**通过判据**：至少两次独立变式正确，且入口判断在 **30 秒内**完成

**退出条件**：仍然"更快地错" → 转反路径训练（场景 A+），不继续加题量

---

### 场景 B：地图建立（中频）
**触发**：某章 0 覆盖或 < 20%，不知道缺的是知识还是入口

**目标**：用最小样本建立基线，判断"有底子"还是"断点区"

**取样规则**：
- 按考纲列出"考法簇"（不是按题量最大的叶子简单铺开）
- **每个考法先取 1 题**，题型错开，优先让题面能区分方法入口
- 题量：6-10 题（一次能完整复盘的上限）
- 难度：d1:d2:d3 ≈ 2:6:2（不能清一色 d=1）

**信息控制**：首次诊断**不提前**给完整解答（可给题型范围，不给方法提示）

**通过判据**（正确率三档）：
- **≥ 70%** → 有底子，转间隔复习
- **40-70%** → 正常，下一轮同考法再取 1 题确认
- **< 40%** → 判为断点，转场景 A 入口修复

**禁止行为**：连续 id 段（如 #3107-#3113 必然全落同一叶子）

---

### 场景 C：原题验收（中频）
**触发**：修复卷做完后，要确认是否真修好了

**目标**：确认内化，不是再练一遍

**取样规则**：
- **原题重做，绝不出新题**（新题测不出"这道题的动作是否刻进去了"）
- 题量：2-5 题（就是上一轮错的那几道）

**通过判据**：**耗时降到首次的 1/3 以下**

| 题号 | 首次 → 复习 | 判定 |
|---|---|---|
| #10587 | 808s → 451s → **45s** (1/18) | ✅ 真内化 |
| #10578 | 105s → **12s** | ✅ 真内化 |
| #1052 | 1257s → 656s（只降一半） | ❌ 假掌握 |

**未通过处理**：回文档再"学"一遍，**不推进新题**

---

### 场景 D：反脆弱抽检（低频）
**触发**：某章 ≥ 60%，或你已视为王牌，要确认强项不是被固定模板保护

**目标**：测试能否承担迁移任务

**取样规则**：
- 不再刷同一母题，选 2-4 道改变表示/提问顺序/参数位置的题
- 至少一题保留优势入口，另一题故意让优势入口不够直接

**通过判据**：
- 优势方法在新外观下仍成立 → 减少该类训练频率
- 只在熟悉外观下成立 → 降级为"局部固化"

---

### 场景 E：跨章迁移（低频）
**触发**：两章以上已分别通过，要测"题目不告诉你属于哪章时能否选工具"

**取样规则**：
- 按**共同结构**组题（不是按章节标签）
- 优先"降维""不变量""算子""对称/交换""边界闭环"等可跨章迁移的能力
- 题面不标注章节和推荐方法

**记录重点**：第一分钟做了什么、写下了哪些候选入口、何时排除错误路线

**通过判据**：能主动提出正确工具，且至少一题能解释为什么其他常见工具不合适

---

### 场景 F：节奏与止损（考前 60 天高频）
**触发**：需要训练速度、连续作答、放弃纪律

**取样规则**：
- 混合已掌握和半熟考法，控制每题只放一个主要难点
- 长题和短题交错，把"值得继续"和"应先留下可得分步骤"的题都放进来

**执行规则**：
- 开始前给总时间和每题建议预算，但不标注难度
- 到预算点先记录当前结论/卡点/下一步，再决定继续或跳过

**通过判据**：同等正确率下减少无效停留（不是单纯追求更快）

## 四、题组构造的五条操作规则

### 规则 1：每道题必须有角色
| 角色 | 作用 | 在题组中的占比 |
|---|---|---|
| **锚题** | 让目标动作有清晰落点，负荷低，便于观察入口 | 第 1 题 |
| **分叉题** | 放入容易混淆的两个入口，测试能否排错 | 第 2-3 题 |
| **迁移题** | 换外观/变量/问法，测试动作能否迁移 | 第 4-5 题 |
| **压力题** | 增加书写量或时间约束，测试节奏和止损 | 可选，场景 F 必备 |
| **哨兵题** | 间隔一段时间后少量抽查，防止误判固化 | 场景 D |

### 规则 2：单叶子抽取上限（继承 v1 规则 1）
| 叶子题量 | 单卷上限 | 单轮上限占比 |
|---|---|---|
| 1-9 题 | **1 题** | ≤ 25% |
| ≥ 10 题 | 2 题 | ≤ 25% |

**检查方法**：统计"题数 / 不同叶子数"，> 2.5 即塌缩，打回重取

### 规则 3：难度梯度 2:6:2（继承 v2 规则）
- **20% d=1**（概念破冰题）：验证基本概念，耗时应在基准 50% 以内
- **60% d=2**（中坚真题主力）：对齐数一考场中档题
- **20% d=3**（反直觉/压轴好题）：探测高压下的思维抗卡死能力

**⚠️ 注意**：选择题只有 d=1 和 d=3 两档，完全没有 d=2。要梯度就用 d1 选择 + d3 选择混搭，或接受少量 d2 主观题。

### 规则 4：通用前置检阅 7 步（继承 v1）
1. **严格前缀统计**：`高等数学/级数%` 不是 `%级数%`（后者会串章）
2. **剔除同名不同章**：逐个核对 `category_path`
3. **跨类去重**：LaTeX 归一化后比哈希，**检查 id 连续性**
4. **剔除"待统一删除"**：题干含【待统一删除…】的 10 题
5. **核对答案完整性**：`correct_answer` 与 `explanation` 均非空
6. **核对已做题次**：避免把做过的题当新题推（除非验收卷/复习卷）
7. **叶子分布核算**：题数/不同叶子数 ≤ 2.5

### 规则 5：答案与提示的时机（继承 v3）
| 场景 | 给不给答案 | 时机 |
|---|---|---|
| 场景 A（入口修复） | **不给** | 卡住后给"下一动作"级提示，完整解答留到本题结束 |
| 场景 B（地图建立） | **不给** | 可给题型范围，不给方法提示 |
| 场景 C（原题验收） | **给** | 已修复的动作不需要再考识别 |
| 场景 D（反脆弱） | **不给** | 测试迁移必须独立完成 |
| 场景 E（跨章迁移） | **不给** | 工具选择是核心目标 |
| 场景 F（节奏与止损） | 考后给 | 先测速度和决策，批改时再给 |

## 六、推送后的反馈循环（关键）

### 6.1 五种结论（不只说"做得不错"）
1. **知识已补上**：能说出定义和前提，并在独立变式中使用
2. **入口已建立**：能识别并排除旧路线，但执行仍需精度训练
3. **局部通过**：原题或近变式通过，换壳证据不足，进入观察状态
4. **错误路径仍在**：做题更快但入口选择仍错，暂停扩题，改做反向辨认
5. **证据不足**：题量/提示/疲劳不允许下结论，安排更小的区分样本

### 6.2 错题分流（不同病因不同药方）
| 错误类型 | 表现 | 分流到 |
|---|---|---|
| 概念缺口 | 不记得公式/定理 | 最小教学样本（1-2 题低负荷） |
| 入口选择错 | 知道但不敢用/选错路 | 场景 A 入口修复 + 分叉题 |
| 错误路径自动化 | 复习时"更快地错" | 反向辨认（先写排除理由） |
| 边界/闭环遗漏 | 模型对但末行失误 | 短题补最后动作（不重讲模型） |
| 代数/书写错 | 方向对但算错 | 精度抽检（保留中间检查点） |
| 耗时过长 | 慢但方向正确 | 先确认有无更短路径，再做节奏题 |

### 6.3 什么时候才算"固化"
满足以下**所有条件**才标记为"可降频"：
- 至少两次独立成功
- 一次换壳成功
- 没有依赖提示
- 耗时不超过该题型的合理预算
- 最近一次没有新的相同机制错误

**所谓"已固化"仍需后续哨兵题维护，不是永久封存。**

## 九、给学员的承诺

从今往后，我推题时会：

1. **先扣除复习位**（8 题 / 28′），不让你"狗熊掰棒子"
2. **先回答三问**（测什么、为什么选、做成什么样算通过），说不清就不推
3. **给每道题分配角色**（锚题/分叉题/迁移题），不是题目列表
4. **通过 10 秒自检清单**，不让低级错误上线
5. **做完给五种结论之一**，不只说"做得不错"

你的题目取样应当服务于**能力迁移和考场决策**，而不是服务于题量、章节数量或看起来很满的日程表。
